# Sanghak Choi | Finance | Yonsei University

Academic website for Sanghak Choi, Division of Business Administration, Yonsei University MIRAE Campus.

This repository contains a static website intended for GitHub Pages. The Korean version is the default. The language switch changes interface text to English; publication titles remain in their original language.

## Deployment

Repository: `choi-sanghak/sanghak.github.io`

GitHub Pages URL with this repository name: `https://choi-sanghak.github.io/sanghak.github.io/`

To publish, open **Settings > Pages**, choose **Deploy from a branch**, **main**, **/(root)**, and save.

For the shorter address `https://choi-sanghak.github.io/`, rename the repository to `choi-sanghak.github.io` and reconfigure Pages if necessary.

## Updating content

- `publications.json`: Publications and working papers, sourced from the CV updated October 2026.
- `index.html`: Academic profile, teaching experience, research areas, contact information.
- `app.js`: Language labels, publication search, year filter and responsive menu.
- `styles.css`: Styling; all text sizes are restricted to **13, 15, 20, and 28 px**.
- `assets/yonsei-logo.png`: User-provided Yonsei logo.

The public site omits education dates and a personal mobile number. The short biography about earlier education and the BK21 appointment was removed from the introduction at the user's request. No individual portrait is used.

The author details and article metadata should be reviewed against the latest CV before future updates. Publication links intentionally point to academic search rather than unverified DOI targets.
